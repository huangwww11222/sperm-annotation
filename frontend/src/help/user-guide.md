# 微流控标注工作台使用说明

默认部署启用 SAM3 AI 辅助追踪：先人工标出起始帧目标，再使用 AI Tracking 生成后续帧的候选标注并检查修正。服务器需要准备 GPU，默认部署自动获取本仓库提供的模型；仅人工部署是可选模式。

适用于视频标注、审查、对比确认及训练数据集导出。页面上的帧号从 1 开始。可由同一账号完成整个流程，也可分工协作。

## 开始使用

完整流程：人工标注 → 审查模式 → 对比确认 → 导出训练数据集。

1. 登录后，在人工标注页导入视频，在画面中标出目标。
2. 服务器启用 AI Tracking 时可辅助追踪；也可纯人工标注。检查整段视频的标注，有错误时在对应帧修正。
3. 点击“完成标注并送审”，检查全视频覆盖并确认送审。
4. 进入“审查模式”，逐帧检查并点击“提交本帧”，最后完成视频审查。
5. 进入“对比确认”，对每个修改项选择原标注 A 或审查标注 B，最后完成视频确认。
6. 在“确认本项”下面的导出区域生成并下载训练数据集。

标注记录只是人工标注记录的查询入口，不需要先进入它才能送审，也不能把它当作最终训练数据。

同一账号可以检查自己的标注。任务被其他账号领取后，当前账号仍可查看，但不能编辑该任务。

三个工作页面的操作位置保持一致：顶部看视频与阶段状态，左侧选视频，中间看图，图下浏览帧或修改项，右上执行当前阶段的核心操作，右下选对象或修改项。左侧“收起视频列表”可腾出图像空间，收起偏好在三个页面间沿用。长列表在区域内滚动，核心操作保持可见；人工标注和审查中的详细数据需要时再展开，对比确认直接结合完整帧与 A/B 图像判断。

## 人工标注

1. 点击“导入视频”，在左侧素材库中选择要处理的视频。可通过时间轴、上一帧/下一帧、帧号输入定位。
2. 按 B 切换画框工具，拖动框住目标；按 V 选择已有框，拖动移动、拖角缩放。训练数据使用框标注，标点不等同于框。
3. 点击右侧“当前帧对象”列表或画面中的框选中对象，两处同步高亮。列表与对象操作共用一个面板，可查看名称、来源、稳定对象 ID 和标注覆盖帧数，再修改名称、移动、缩放或删除；需要精确数据时展开“位置与尺寸”。需要继承上一帧时，点击“复制上一帧”，只补充本帧缺少的对象。
4. 本帧有框后，点击“AI Tracking”。暂停时先检查提示对象，同时查看前几帧是否已经出现框偏移，再明确选择“无异常”或先修正框后确认；多个异常对象需要逐个确认，全部处理完才继续。异常标题固定显示实际暂停帧，浏览其他帧不会改变提示；返回暂停帧后才能确认。专注模式保留相同的异常确认入口。
5. 追踪不会代替全视频质量检查。从较早帧重新追踪会重建该帧之后的分支，应先确认操作起点。开始新一轮追踪后，旧的撤销/重做记录会清空。
6. 顶部显示当前帧、含标注帧数和保存状态；含标注帧数不等于已经检查完成。完成后点击顶部“完成标注并送审”。未知帧不会自动算空帧；先检查这些帧，补标，或在确认无目标后填写空帧范围（例如 3, 8-10），再确认送审。

撤回送审与重复导入

- 送审后，顶部显示任务状态。审查员尚未领取时，送审者可点击“撤回送审”，确认后继续修改工作区并重新送审。领取即视为开始审查；已领取、已审查或已确认的视频不能撤回。撤回保留工作区标注和历史 A 快照，原任务不再可编辑。
- 相同视频按文件内容识别，即使改了文件名也会提示“该视频已存在，是否覆盖重新标注？”。同名但内容不同的视频分别保存。
- 点击“取消导入”放弃本次导入，旧标注保留；点击“覆盖并重新标注”舍弃该视频旧工作区的人工框、AI 追踪、删除规则、校准和撤销记录，返回第 1 帧（API 帧号 0）从头标注。覆盖不能撤销；历史送审快照保留，不作为新的标注进度。
- 已送审且尚未领取的视频必须先撤回，再重新导入；已经进入审查则提示“已送审无法重复导入”。弹窗打开后服务端仍会再次检查状态和版本。
- 覆盖的保存结果不确定时保持弹窗，使用“重试覆盖”；刷新后也可重试同一请求，避免重复清空。导入失败不会增加假素材。已有视频和工作区自动从服务器恢复，不再提供“加载标注”文件夹入口。

如果 AI Tracking 提示服务器未启用，当前是基础部署模式，可以继续人工标注、审查、确认和导出；需要 AI 时请联系部署人员配置 GPU 与 SAM3 模型。

4K 视频与失败恢复

- AI 每轮只读取当前帧起的连续追踪窗口，保留原视频分辨率、FPS、帧号和框坐标。界面显示读取原始帧、准备模型、追踪和保存结果的阶段；大视频和首次加载模型仍可能耗时较长。
- 服务器视频的 AI 结果从服务器恢复，人工修改继续自动保存。读取 AI 结果失败时会锁定编辑并显示“重新读取工作区”，避免把尚未读到的框当成空帧；恢复连接后用该入口重新加载。
- 追踪失败会持续显示失败阶段、帧号和原因，不会随短提示消失。工作区“已保存”不表示追踪成功；“重试保存”也不能修复模型或追踪查询失败。
- “重试追踪”从当前帧重新准备；“重新查询追踪任务”只查询原任务，不再启动模型；“重试原追踪请求”用于确认启动回复丢失的结果。任务结果未确认前保持编辑锁，刷新后也可查询原任务。若服务器重启导致旧任务不存在，先检查已保存结果，再重新追踪。
- 保存失败保持错误信息，成功保存后才清除。若显示“重新读取工作区”，点击后需确认采用服务器状态，工具先下载本地标注备份；删除或异常确认失败则使用对应的原操作重试入口。请保留失败阶段、帧号和控制台诊断信息供管理员按日志排查。

删除对象与恢复

- “删除本帧”和 Del / Backspace 只移除此视频、此对象在当前帧的标注，其他帧保留。删除后取消对象选择，连续按删除键不会自动改选并删除下一个对象。
- “删除全视频…”按稳定对象 ID 移除整段视频中此对象的人工标注、AI 标注及续追种子。先查看确认窗口中的实际涉及帧数、人工/AI 数量与首末帧，再确认。读取范围失败时必须重试，不能把未知范围当成 0。
- 全视频删除规则会保存；刷新、重新读取追踪结果、续追不会自动恢复已删对象。其他对象、原视频和已固定的 A/B/F 快照不受影响。删除标注不会擦除视频画面中的物体。
- 主动删除的对象不会因为旧追踪历史而被判成“框消失”。单帧删除只跳过该帧；后续仍在追踪范围内的对象继续接受正常异常检测。
- 误删时点击删除反馈中的“撤销”，或使用工具栏撤销、Ctrl/⌘ + Z，恢复原框与原对象 ID；不需要另画一个对象。单帧撤销按帧隔离，全视频删除作为一整次操作恢复。普通单帧历史刷新后不保留；最近一次全视频删除可在当前标签页刷新后继续撤销，关闭标签页或启动新追踪后不保证恢复。后续修改可能使旧操作无法安全撤销，请及时撤销并检查保存状态。
- 删除或撤销请求失败时保留待重试操作，不显示成功；点击“重试本次删除/撤销”确认原请求结果。不要用新对象或新的删除范围替代尚未确认的请求。

异常确认与后续判断

- “无异常”表示你已核对当前框仍对应正确目标。确认保存成功后使用当前有效框继续追踪；普通 AI 输出不会自行成为已确认正常样本。
- 对涉及运动的提示，默认勾选“用本次正常运动确认减少同类暂停”：记录本视频、此对象的正常运动样本，后续幅度相近且尺寸稳定、目标仍被追踪的同类变化可合并提示并继续。取消勾选不调整正常运动判断，仍保存本次人工确认。记录会在刷新、续追时继续生效。
- 对尺寸缩小、扩大或形状变化的提示，点击“无异常”会将当前框的尺寸和形状保存为本视频、此对象的额外判断参考，后续与原人工框或该已确认框相近的形态可继续追踪，无需为了确认而重新画框，也不修改原人工标注。只有明确的人工正常确认才添加参考，普通 AI 输出不会逐帧扩大范围；后续新的尺寸或形状变化、目标丢失、对象重叠仍会检查。后来实际修改的人工框优先作为新的判断依据。尺寸确认和运动校准分开，取消运动复选框仍会保存本次尺寸确认。
- “已修正框”表示你已经在画布移动或缩放了错误框；先修正，再点击确认。修正后的框成为新的人工基准，不会将原错误框当成正常样本。
- 正常运动确认只调整有限的同类判断；新的持续偏离、目标丢失、形状突变或身份混淆风险仍会检测。尺寸确认不会关闭这些检测；目标丢失、对象重叠提示不能扩大正常运动范围。
- 点击对应对象的“恢复默认判断”可清除本视频此对象的正常运动校准和已确认尺寸参考，恢复按人工标注和默认运动范围判断，历史人工决定仍保留。“已保存的正常确认”展示记录过的确认；后来修改的人工框优先，浏览到确认帧之前不会提前应用之后的尺寸确认。该功能用于调整异常判断，不会训练或更新 AI 模型。
- 确认或恢复默认判断失败时，提示和原决定保留待重试；用“重试本次确认/恢复默认判断”重放原请求，成功前不能更换对象或决定。普通“AI Tracking”按钮不能代替异常确认。

显示辅助

- 专注模式占用整个浏览器工作窗口；按 F 切换。Esc 优先取消当前拖动，没有拖动时退出专注。退出后恢复原缩放。
- 放大镜、亮度、对比度和反相只改变预览，不改变原视频或导出标签。图像保持原始宽高比，有留白是正常的。
- 人工框为紫色虚线、AI 框为绿色实线、选中框为金色。可隐藏名称或临时隐藏全部标注以观察原图。
- 空格按住拖动可平移放大的画面；Ctrl/⌘ + 滚轮围绕指针缩放。

保存与续标

- 查看保存状态；“保存失败”时点击重试。尚未保存成功时不要强行关闭页面。
- 重新打开会恢复上次素材、服务端已保存的标注和帧位置。普通单帧撤销/重做历史刷新后不保留；最近一次全视频删除可在当前标签页刷新后继续撤销，关闭标签页或启动新追踪后不保证恢复。
- 暂时不处理当前素材时，直接切换到其他素材即可，已有标注按保存状态保留。
- 素材条目右下角的垃圾桶是“删除素材”：服务器视频在确认后删除共享原视频、工作区和追踪文件，其他使用者也无法再访问，不能撤销。已送审的视频受原始快照保护，不能删除。删除失败会显示原因并保留条目；成功后刷新不会恢复。
- 本地导入的图片也使用“删除素材”，确认后仅清除本机工作区中的图片条目和标注，保留电脑原文件与服务器已保存的标注记录。请根据确认窗口中的实际删除范围操作。

## 审查模式

1. 选择左侧已经送审的视频，领取尚未分配的任务并开始检查。
2. 观察本帧每个已有框。正确的框不用操作；不准确的框直接移动或拖角缩放。审查阶段不能新增、删除或改类别。
3. 右侧对象列表默认显示本帧全部框，可按 ID 搜索或仅看已调整对象，点击条目定位框。需要时叠加原框，或选中对象展开对比详情，查看同范围 A/B 局部图、IoU、位移、尺寸和坐标。它们表示改动幅度，不代表哪一个框更准确；“未调整”也不代表已完成审查。
4. 检查完成后点击右侧“提交本帧”。没有改动的帧、没有对象的空帧也必须提交，提交成功后进入下一未提交帧。
5. 查看顶部“视频审查进度”：已提交/总帧、剩余帧以及百分比。所有帧提交后，再点击“完成视频审查”并确认。右上提交与保存状态始终独立于对象列表滚动。

需要区分的状态

- 浏览某帧不会增加进度。
- 改框后自动保存的是草稿，尚未提交，不计入已审查进度。
- 再次修改已提交帧时，它会重新成为待提交草稿；放弃草稿可恢复上次成功提交的结果。
- 100% 表示所有帧已提交，还需要完成整个视频审查。完成后只读，原始 A 始终保留。
- 中途退出后，可恢复已保存草稿和浏览位置，也可展开草稿入口定位。保存失败时保留当前修改，先重试；遇到冲突可先导出本地修改再读取服务器结果。

如果发现漏框，B 无法补画；需要回到人工标注阶段处理来源并重新送审，不能用移动其他对象框来代替新增目标。

若 C 退回某帧重审，审查页会显示对应帧和退回原因。原审查员从上次 B 的框继续检查，可移动或缩放已有框；即使认为原框无需修改，也必须重新“提交本帧”，再“完成视频审查”。其他帧提交保持有效，旧 A/B 快照保留。

## 对比确认

1. 在左侧选择已完成审查的视频，点击“领取并开始确认”。没有修改的视频也需要领取并显式完成确认。
2. 先看中央大幅的“完整帧定位”，确认目标及周围情况；金色外框标出当前对象所在位置，只用于定位。再看旁边上下排列、使用同一范围的 A/B 局部图，比较哪一个框更贴合目标：A 是原标注紫色虚线，B 是审查后绿色实线。可切换“A / B 对照”或“叠加对比”，局部缩放不会裁掉完整画面。需要更大的完整帧时点击“展开”。
3. 选择“保留原标注 A”或“采用审查标注 B”。点击即保存，可再次选择修改结果；可勾选选择后自动跳到下一待确认项。
4. 如需纠正选择，点击“撤销上一次选择”。完整帧中点击有修改的框，可联动切换局部图及右侧列表；用 Tab 聚焦这些框后按 Enter 或空格也可以切换。未修改对象淡显，不需要逐个确认。右侧按帧分组的列表可筛选全部、待确认或已确认，支持分页与回访；筛选后当前项不在列表时，可点击“定位当前项”。主图下方的上一项/下一项浏览的是修改项，浏览和定位不会替你选择 A/B。
5. 全部修改项都选择后，在完成提示中确认完成；如选择继续检查，可从顶部“完成本视频确认”再次进入。

同一帧中切换不同对象会复用已加载图像，减少闪烁和等待；每次 A/B 选择仍独立保存。若其他窗口同时操作，程序会按服务器版本更新列表和进度，冲突时保留您的操作并提示处理。
6. 完成后，“确认本项”下方显示导出区域。选择入口会进入只读状态，避免改写已完成版本。

只需处理审查员真正修改的对象，未修改对象自动保留 A。进度 100% 仍需要完成视频确认。无修改项的视频显示 0/0，可直接点击完成按钮确认，而不是跳过本阶段。

如果需要调整已完成的选择，使用“重新确认”；已有选择会保留。重新确认期间暂停训练导出，再次完成后使用新的最终版本。

如果 A、B 都不合适，在右上“确认本项”区域点击“A / B 都不合适，退回本帧重审”，填写原因并确认。整个当前帧交回原审查员，不只退回选中对象。重审期间旧确认任务只读，训练导出不可用；其他帧已确认的选择保留。B 重新提交并完成视频后，点击旧任务的“继续新一轮确认”进入新任务；退回帧的修改项必须重新选择，其他帧几何未变化的决定自动保留，最后仍需显式完成视频确认。已完成确认需先“重新确认”才可退回。

重审允许 B 修正已有框的位置和大小，不能新增、删除目标；漏标或对象集合错误不能通过这一操作补齐。

## 导出训练数据集

1. 确认本视频已完成审查与对比确认；导出入口在“确认本项”下面。
2. 点击训练数据集导出按钮，选择 YOLO、COCO 或双格式。YOLO 是默认选项。
3. 查看帧数、对象、类别等预览，设置训练/验证比例（默认 80%/20%），开始生成。
4. 等待后台任务完成，再下载 ZIP。关闭弹窗后服务器会继续生成；回到同一视频的导出窗口可查询任务。
5. 解压后核对图像和标签，YOLO 使用包内 data.yaml。保留 manifest.json 和 provenance/；图片文件名包含数据集身份，可据此查回原视频与帧。完整视频 JSON 是追溯标注的另一种导出，不能替代 YOLO 图片/标签训练包。

训练包包含真实逐帧图像、最终框以及空帧标签。至少需要两帧并含正样本；原视频丢失或内容改变时不能生成。

未完成审查或确认时不能导出。重新确认后，旧训练包暂不可下载；再次完成生成新版本后，应重新生成训练包。已经下载到电脑的旧包不会自动删除，请自行区分版本。

生成或下载失败时，按页面提示重试。服务重启中断的生成任务需要重新生成。连续视频帧的训练/验证划分不能代替不同视频上的效果验证。

## 常见问题

为什么是只读？

任务已完成、已被其他账号领取或历史数据不完整时会显示只读原因。自己的标注可以自己领取审查，不需要换账号。

为什么进度没有增加？

在 B 中需要点击“提交本帧”，自动保存草稿不计进度；在 C 中需要明确选择 A/B，浏览不会替你选择。两者 100% 后还要完成整个视频。

为什么按钮暂时不能点击？

可能正在保存、加载图像或运行 AI，也可能尚未领取任务或未满足完成条件。先查看保存状态、任务提示和错误信息。

保存失败或连接中断怎么办？

先保留页面并重试当前请求。发生冲突时按提示备份本地修改或未决操作，再读取服务器结果。不要反复刷新或假定修改已经成功保存。未成功同步的修改在异常关机后不保证恢复。

如何反馈问题？

记录视频名称、页面、帧号或对象编号、操作步骤和错误提示中的记录号，交给维护人员定位。不要发送密码或登录令牌。
