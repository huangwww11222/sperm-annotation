# 人工标注、画布与 Tracking

这里只维护人工标注阶段的当前交互；B/C 规则见 [WORKFLOW.md](WORKFLOW.md)。

## 布局与辅助显示

常规布局使用三页共享工作台：左侧可收起素材库，中间画布工具与时间轴，右上 AI 追踪、右下当前帧对象及选中对象操作。顶部展示素材身份、当前帧/总帧、含标注帧数、保存状态与送审；含标注帧数不等于已检查进度，送审时另做全视频覆盖校验。对象坐标和尺寸默认折叠，已有正常运动样本才显示校准入口。跨页布局与后续扩展遵守 [工作台规则](WORKFLOW.md#工作台布局与扩展规则)。浅/深主题共用 `style.css` 变量，图像画布保持深色；显示样式不改变训练数据。

**专注模式**使用整个浏览器窗口的宽高，隐藏站点导航与左右面板，仅保留文件/保存/AI/帮助/送审/退出、编辑工具、画布、时间轴和状态。进入时适应完整源图，退出恢复原缩放和滚动位置；窗口高度变化时继续适配。图片保持宽高比，黑边属于正常留白，不拉伸或裁掉源图以填满窗口。浏览器自身的标签栏不属于工作区。

- 普通框 2 屏幕像素，选中框 2.5 像素加轮廓，名称/手柄不随图像缩放失去可读性。人工紫色虚线、AI 绿色实线、选中金色。
- 新框最小 2×2 原图像素；边界受原图限制。人工工作区 bbox 为百分比，不要把鼠标屏幕坐标直接保存。
- 画面增强含亮度、对比、暗场/低对比预设、反相，只处理预览；局部放大镜读源图像素。
- 复制上一帧只补当前帧缺少的 `objectId`；已有对象不覆盖，不重复。普通撤销/重做按媒体及帧隔离，每帧最多 50 步，刷新后不保留。最近一次全视频删除单独记录，可跨帧撤销；该标签页刷新时恢复其记录。重建追踪分支后清空旧编辑历史，避免仅在本机恢复已经被服务端替换的 AI 结果。
- 手势过程仅预览，松手一次提交；取消不保存半次手势，单击选中不把 AI 框转为人工框。人工修改提交后才成为人工来源。

## 读取、响应和保存

- 对象按帧建索引；拖动按动画帧合并预览；不要恢复为每个 pointermove 改写全视频数组。
- 精确帧 Blob LRU 上限 12 帧、32 MiB，相邻预取、同帧请求合并；切换媒体清空、失败不缓存。
- 先解码再同步切换帧号和图像；过期请求不能覆盖新帧。读取失败保留前一个对应帧并锁编辑，重试实际失败目标帧。
- Tracking 全量结果在开媒体/追踪更新节点加载，不在每次切帧重新下载。
- 播放、精确帧读取、恢复或 AI 运行期间锁定用户编辑。**内部 `seekVideo` 仍需支持 AI 完成/暂停定位**，不可用通用 busy 判断挡住；用户导航入口单独判断 AI 锁定。
- 同媒体服务端保存串行，按媒体保留状态；失败显示错误并允许重试，路由离开前保存，失败留在原页。记住上次媒体与服务端当前帧。
- 精确帧读取超时 20 秒，Tracking / 工作区 JSON 30 秒；慢视频首次提帧与浏览器不支持格式的逐帧播放仍受解码/网络限制。
- Chrome 93 / HTTP 兼容入口为 `src/utils/browserCompat.ts`：超时使用 AbortController 和可清理的计时器，覆盖响应正文读取；UUID v4 使用 HTTP 下可用的 getRandomValues。不要在业务代码直接调用 AbortSignal.timeout / crypto.randomUUID，也不要用时间戳或 Math.random 代替幂等键。重试沿用原键。
- 素材列表只提供“删除素材”，不提供临时关闭入口；暂停处理直接切换素材。垃圾桶按钮先确认范围：服务器视频删除共享原视频、工作区和追踪文件；本地图片仅清除本机工作区素材与标注，保留电脑原文件和服务器已保存记录。服务器删除前停止待发自动保存、等待已发送保存结束，收到后端明确成功才移除本机条目。已送审源视频不可删。成功同步服务端列表时剔除失效的本机视频缓存，网络失败不得清空列表。保留旧关闭记录的 ID 映射读取，用于升级后恢复既有标注身份。

## 删除对象与显式确认

- 对象列表、选中身份、名称和删除入口使用同一面板。`删除本帧`以 `(mediaId, frameIndex, objectId)` 保存排除规则，`删除全视频`以 `(mediaId, objectId)` 保存规则；不要用随机界面 `id` 代替稳定身份。旧 `deletedTrackingIds` 仅用于兼容。
- 全视频删除先读取服务端实际统计（同帧人工优先去重），展示涉及帧数、人工/AI 数与首末原始帧，再确认。读取失败不能当零条，成功写盘前不移除本机对象。删除不物理擦掉追踪原始数据，消费者在读取、seed、后续追踪、送审时统一过滤。
- 单帧撤销恢复原框和删除规则；整视频撤销恢复目标对象自身快照，其他对象修改不回滚。删除暂停对象时清除对应待处理项；撤销需恢复尚未确认的暂停项。普通新编辑使旧的整视频删除重做失效；新追踪分支使旧撤销/重做整体失效。
- 工作区、删除与反馈写入统一串行，使用服务端 `revision` 和 `Idempotency-Key`。反馈前先保存人工修框，成功才清对应暂停项；全部处理后才自动从已确认的暂停帧续追。定位失败保留确认结果并要求返回该帧，不在错误帧开始追踪。
- 网络失败保留原 payload/key，禁用新的互斥决定，允许原请求重放；待重试数据与最近一次全视频撤销快照按账号、媒体存于当前标签页 sessionStorage。刷新先重放再 GET 核对状态。版本冲突不自动覆盖另一份工作区，要求重新读取。
- 右上角用户说明唯一源是 `frontend/src/help/user-guide.md`，专注入口复用同一组件；快捷键小窗也从该源的表格生成。

## 稳定 ID 与人工基准

`objectId` 是媒体内稳定正整数；同帧不重复，不按数组顺序或长度生成、重排。seed 同时传 `object_id` / `objectId`，后端拒绝缺失、重复或跨帧身份；SAM3 输出、工作区合并、后续 seed 都沿用该身份。前端合并键为 `(frameIndex, objectId)`，人工修正优先于同对象 AI 结果，并保留删除标记。

异常面积/宽高/长宽比默认按每个对象最近一次人工基准比较。尺寸/形状提示经“无异常”确认后，另外保存该帧实际追踪框作为人工确认参照，无需移动或重画；原人工记录及其来源保持不变。后续完整几何匹配原人工基准或最新确认参照之一时不因同一形状重复暂停，不能按不同参照拼接单项范围。AI 不自动更新参照；更新或同帧人工修框优先于旧确认。异常先保存结果再暂停，并定位实际 `pausedFrame`；正常定位 `lastProcessedFrame`，不猜测处理终点。

### 运动提示、人工确认和续追

- 位移使用 `motion_normalized = 中心位移 / 人工框对角线 × FPS / (30 × 真实帧差)`；人工尺度缺失的历史输入使用固定 seed 尺度。最小尺度与初始阈值集中在 `AnomalyConfig`，没有固定 40/55/60 px 门槛。帧间隔和分辨率改变时，相同相对运动的判断保持一致。
- 普通超范围先产生 warning；连续 3 次超范围才暂停。近期轨迹中的有限往返抖动中断持续漂移计数；远超范围的跳跃仍立即暂停。AI 历史最多 8 帧，只用于短期运动证据，不会扩大正常阈值。
- 暂停后显式选择“无异常”或先修正再确认。服务端从保存的追踪结果提取人工确认对应的运动特征；只有选择校准的 `normal` 决定写入本媒体 `normalMotionSamples`，按 `objectId` 和 `reason=motion` 适用。只确认本次、修正、其他异常类型不能变成正常运动样本。
- 校准以已确认样本及有限余量调整同类运动范围；再次人工确认可补充更大样本。刷新、后台重启与续追重新读取持久样本；重置清除该对象的校准，不删除确认审计历史。相似运动在范围内持续追踪，warning 按对象和原因合并计数，不每帧弹窗。
- 正常尺寸参照随服务端反馈事件持久化，仅对同媒体、同对象生效；续追只读取不晚于起始帧且未被后续重置/修正取代的参照，不让未来确认影响回退起点。恢复默认判断清除运动校准和尺寸参照的使用，审计保留。尺寸确认与运动勾选独立：取消运动校准不撤销对当前尺寸/形状的认可。
- 新的持续超范围运动、明显跳跃、超出已认可形状的尺寸突变、非正常离场的目标丢失、对象重叠仍分别检查；运动校准不会停用这些检测。这里没有在线训练 SAM3，模型推理质量与异常暂停规则是两层功能。
- `tracker_results.json` 保留逐帧位移、归一化值、阈值、持续次数、样本数、近期速度，以及实际几何参照来源/帧号/框等诊断；`review.tracking` 记录 `tracking.anomaly_pause` 与合并警告。发现频繁暂停先查看这些依据和人工反馈记录，再调整规则。仅合成轨迹/模拟推理回归通过不等于真实 GPU 或真实视频效果验收。

## Tracking 回退的精确边界

点击当前 N 帧 Tracking：先保存工作区和当前人工修改，回退旧未来结果，再将 N 帧当前全部 bbox（含仍有效的 AI 对象身份）写入 seed 并启动新分支。暂停异常须先完成显式人工确认；普通启动/续追不能隐式确认所有异常，也不能让普通 AI 框自动覆盖最近人工基准。

当前实现 `tracker.rewind_tracking_results` **保留 ≤N 的行，仅删 >N 的旧未来追踪行**；持久人工标注和基准文件保留。前端保留当前帧及之前有效框，清掉当前工作区 N 之后的旧对象与追踪帧；随后新追踪按原始帧身份更新 N 及之后的新结果。旧文档的“删除 >=N”或“删除未来人工 seed 文件”不能照搬。

全程原始 FPS/帧号，无 FPS 降采样、sample-frame 编号或浏览器插值。`SAM3_TRACK_FRAMES` 包含 seed；模型缓存跨任务复用，每个任务建立推理会话，GPU 队列串行。

回归入口：`test_anomaly_detector.py`、`test_tracking_adaptive_feedback.py`、`test_tracking_rewind.py`、`test_seed_identity.py`、`test_manual_baseline_restore.py`、`test_frontend_tracking_contract.py` 以及 [TESTING.md](TESTING.md) 的浏览器用例。模拟 AI 响应只验证 UI 状态/定位，不代表模型推理通过。
