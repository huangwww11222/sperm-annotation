# 人工标注、画布与 Tracking

## 2026-10-29 当前入口

当前标注页仅显示“首尾双向追踪”，新请求默认 edgeDiscovery=true，忽略旧关闭偏好。头框生成、手动微调、删除与撤销保留。顶部以“导出训练数据集”替代送审；旧任务仅显示状态/撤回等恢复操作。导出先保存完整工作区，服务端校验后固定独立快照，不创建审查任务。

这里只维护人工标注阶段的当前交互；B/C 规则见 [WORKFLOW.md](WORKFLOW.md)。

## 当前默认：追踪后集中审查

“首尾双向追踪”使用独立人工首帧/尾帧；普通模式右上 AI 区提供首尾跳转、人工框计数与启动入口，专注模式保留首尾跳转和双向启动。启动需明确确认两端已完整检查，空尾帧明确提示无法提供反追依据。尾帧可独立编号，不要求人工猜对应身份。当前帧“AI Tracking”保留原续追语义。

双向请求从0帧开始；源头框使用人工首帧快照，尾框使用本次已保存人工尾帧快照。恢复查询/启动重试沿用原键原正文；服务端拒绝 AI 冒充人工、缺框/重复ID、错误帧和与保存工作区不一致的端点。反向按最多16帧的重叠窗口运行，`endpoint_tracking.py` 建立对应，`joint_tracking.py` 综合双向及头部检测候选，实际修改中间帧初稿。新请求 combineResults=true，旧仅核验请求保持兼容。

标注画面仅显示一套综合框，不展示采用理由、原正向/反向/检测候选叠加或来源指标。人工几何与删除优先，综合框沿用正常选择、微调、撤销与保存流程。检测器缺少一次候选不删对象；所有方向都缺失时不插值假框；未知内部检测不创建新ID。原图逐帧读取、候选ROI分块/批量上限4，内存不保存全视频图像。检测器失败明确失败并记录日志，不能显示综合完成；默认头部权重随普通 Git 提供，依赖已纳入 requirements.txt；HEAD_DETECTOR_MODEL 仅供自定义覆盖。

唯一对应的尾框在加载结果时统一为正向对象ID；原始局部ID保存在 endpointOriginalObjectId 和不可变锚点证据中。endpointAnchorHash 防止刷新/重试重复转换。整段删除和继续追踪采用统一身份；未匹配尾框仍是独立对象，交给审查判断。

首尾身份关联补充 `first-anchor-v2`：反追返回独立首帧人工头框的唯一位置关系，并有至少3个连续帧位置支持时，优先于后半程已经共追邻居造成的错误匹配；框松紧通过包含率及中心距离联合核对，不按ID或面积合并。历史结果使用已保存的正反向分歧恢复观测，统一读取投影纠正明确错配；端点哈希相同但对应更新时，仍从 endpointOriginalObjectId 重新映射，不能把旧 canonical ID 当尾帧原编号。人工坐标及原始结果文件不改写，API/JSONL/导出来源一致。

`track_lifecycle.py` 的 `boundary-exit-v1` 保护综合输出：连续三帧向边缘移动、可见高度/宽度明显裁切、运动预测到达边界，同时原图/Mask已记录主体丢失或共核风险，且当前和后续帧捕获了此前独立存在的邻居，才终止该身份。真实人工重锚和明确人工尾帧对应优先；普通重叠、画内遮挡、单帧接触、缺图像风险或缺帧不自动判出画。读取投影不写删除墓碑、不删除原始框；人工修改仍由工作区优先合并。它是保守保护，不代表已解决所有出画或身份交换场景。

前端新请求固定 `reviewMode=true`，服务端 `_run_tracking_task` 分段自动续跑至末帧；不通过前端反复保存人工 seed。`continuation_row` 仅内部使用，保留 AI 来源、疑点、预期对象集合和边缘状态。段内模型/IO失败仍失败；没有可用末帧框则停止并保留已发布结果，不用陈旧框冒充当前图像。

`review_evidence.py` 使用独立检测候选对照头部，原图主体证据/缺失贯穿逐帧，反向核验仅有界补查。疑点存于同一原子发布的 Tracking 行，送审时随来源摘要固定到审查任务。所有单框确认/阈值学习/自动暂停内容仅适用于旧暂停兼容路径；不应用于新默认流程。首次版本的启发式门限不构成精度承诺。

## 布局与辅助显示

人工标注、审查、对比确认共用“画面优先”外壳 `components/WorkbenchShell.vue` 与 `workbench/shell.css`；人工标注内部内容由 `pages/AnnotatePage.vue` 和 `annotation/annotation-shell.css` 管理。视频身份、当前帧、含框帧数、保存状态与送审入口放入站点顶栏的 `#app-header-context`，专注时移到画布上方细栏。左侧窄栏打开素材抽屉（未选中时展开，选中后收起，M 键切换）；右侧检查面板包含 AI 追踪或暂停核对、本帧人工/AI 框数、选中对象操作和对象编号，可收起，普通模式暂停时强制展开。

中间画布保留主要空间，工具条和增强面板位于画面左上，缩放控件位于右下；`AnnotationMinimap.vue` 在图像放大到超出可见区域后提供点击/拖动平移。底部使用共享 `WorkbenchFrameStrip.vue`，按人工 / AI / 无框 / 追踪提示 / 暂停着色；空间足够时每帧一格，最多 240 格，窄窗口按可用宽度合并区间。缩放每档 ×1.25，上限为适应尺寸的 10 倍。当前单类头框界面提供选择/画框/点选头部，不提供新建标点和对象改名；旧工作区里的标点仍保留显示，恢复到标点工具时自动切回画框。浅/深主题共用 `style.css` 变量；Chrome 93 不支持 `color-mix`，新增颜色用显式主题变量。显示样式不改变训练数据。

已有视频及工作区自动从服务器恢复；不再保留人工选择文件夹的“加载标注”功能。导入按原文件 SHA-256 判断重复，取消不新增目录/素材，覆盖重新标注清空活动工作区及追踪并回到 0 帧；相同名称但不同内容不覆盖。已送审未领取必须先撤回，已领取或后续状态禁止覆盖；进行中的审查可由当前审查员退回重新标注，旧任务关闭后原工作区可继续修改，无须重新导入。覆盖使用工作区版本、幂等键与可恢复文件日志，旧客户端及旧版本不能重新写入已舍弃数据；历史 A 不删除。实现见 `media_reimport.py` 与 API/存储文档。

**专注模式**使用整个浏览器窗口的宽高，隐藏站点导航与左右面板，仅保留文件/保存/AI/帮助/送审/退出、编辑工具、画布、时间轴和状态。未暂停时进入会适应完整源图，退出恢复进入前的缩放和滚动位置；暂停修框时切换专注保留当前渲染倍率与所选对象，避免重新适应导致视野跳动。窗口高度变化时继续适配。图片保持宽高比，黑边属于正常留白，不拉伸或裁掉源图以填满窗口。浏览器自身的标签栏不属于工作区。

暂停处理不再使用高大的图下信息块：普通模式复用右上 AI 操作区；专注模式图下只保留紧凑的暂停帧、对象入口、简短原因及确认操作。两个模式固定使用“本对象无异常”“已修正本对象”，最后一项不改名，全部待处理项保存成功才续追。完整检查依据与运动学习选项在按需侧区独立滚动，已保存正常确认保留独立折叠入口，展开不覆盖图像、不减少画布高度；专注仅显示精简检查侧栏，不恢复整套素材和对象面板，窄屏仍可收起详情。短高与窄屏通过区域或页面滚动保留可修框的画面及可达操作。打开/关闭详情不重新适应缩放、不改变所选对象、不抢编辑焦点；框仍可见则视野不动，侧栏变窄后框被裁到视野外才最小平移。拖框时不自动展开/收起。侧栏内 Esc 或“收起检查依据”关闭详情并将焦点返回入口；其他位置 Esc 行为不变。未暂停时进入退出专注仍遵循原有视图恢复规则；暂停时继续当前修框视图。

检查依据按当前对象、判断数据、参考/检查帧、确认范围四层排列。对象身份与原因先显示，已有数值与界限用指标对照区分，人工/正常确认参考及建议回看帧独立成组，单对象/整帧确认和学习说明另成信息卡；不再将 `metrics`、摘要和操作解释拼成一整段正文。只重组实际诊断，缺少的指标不填 0、不编造置信度，也不由前端增加风险判断。其他对象的依据保留可辨认入口，不能与当前对象的参考混在一起。

- 普通框 2 屏幕像素，选中框 2.5 像素加轮廓，名称/手柄不随图像缩放失去可读性。人工紫色虚线、AI 绿色实线、选中金色。
- 新框最小 2×2 原图像素；边界受原图限制。人工工作区 bbox 为百分比，不要把鼠标屏幕坐标直接保存。
- 画面增强含亮度、对比、暗场/低对比预设、反相，只处理预览；局部放大镜读源图像素。缩放按钮位于画面右下角，暂停时隐藏画内操作提示；可通过平移让待修框与浮动控件错开。
- 工具栏不再提供复制上一帧及 C 快捷键；暂停缺失对象的恢复操作仍只补当前帧缺少的 `objectId`；已有对象不覆盖，不重复。普通撤销/重做按媒体及帧隔离，每帧最多 50 步，刷新后不保留。最近一次全视频删除单独记录，可跨帧撤销；该标签页刷新时恢复其记录。重建追踪分支后清空旧编辑历史，避免仅在本机恢复已经被服务端替换的 AI 结果。
- 手势过程仅预览，松手一次提交；取消不保存半次手势，单击选中不把 AI 框转为人工框。人工修改提交后才成为人工来源。

## 读取、响应和保存

- 对象按帧建索引；拖动按动画帧合并预览；不要恢复为每个 pointermove 改写全视频数组。
- 全视频对象使用浅层响应状态；一次编辑替换对应媒体数组，禁止原地改写对象/数组后期待深监听。服务器视频的本机标注缓存只保留人工框，AI 从服务器恢复；本地图片保留原缓存规则。加载 AI 失败时锁编辑并明确重新读取，不能按空结果继续。大量 AI 不反复写入 localStorage。
- 新上传、删除重传及覆盖重标后尚未生成 AI 结果是正常状态，允许画框、保存及首次追踪，不能据此把视频帧标记为已知空帧。结果已生成后缺失、格式损坏或网络失败才进入读取保护；错误显示实际原因。任务报告成功/暂停后必须读到结果，不能将“尚未生成”冒充追踪成功。本地图片不继承服务器工作区或账号切换的读取锁。
- HTTP 200 的结果也校验结构与身份。完整重读只使用当前服务器 AI 集合，已撤销的未来分支不保留；人工编辑继续优先。工作区恢复的每个 await、错误及结束状态都校验素材、请求轮次与账号，旧素材的迟到失败不能锁住新素材。
- 精确帧 Blob LRU 上限 12 帧、32 MiB，相邻预取、同帧请求合并；切换媒体清空、失败不缓存。
- HTTP 200 的 Blob 也可能无法解码；三页解码失败时剔除对应缓存，重试重新下载，不能重复读取同一坏 Blob。失效前的在途请求不能回填新缓存。
- 后端精确帧解码器最多 2 个，连续/邻近帧复用解码器；随机访问失败按顺序抵达目标，不能回传第 0 帧。JPEG 原始尺寸/质量不变，按源文件签名校验并原子发布，每视频最多 128 帧/128 MiB，超限清派生缓存。B/C 共用另一个 8 帧/32 MiB Blob 缓存，C 在同一固定帧中切换对象复用图像与 A/B 上下文；跨帧仍校验上下文，业务决定/游标照常保存。
- 先解码再同步切换帧号和图像；过期请求不能覆盖新帧。读取失败保留前一个对应帧并锁编辑，重试实际失败目标帧。
- Tracking 全量结果在开媒体/追踪更新节点加载，不在每次切帧重新下载。
- 播放、精确帧读取、恢复或 AI 运行期间锁定用户编辑。**内部 `seekVideo` 仍需支持 AI 完成/暂停定位**，不可用通用 busy 判断挡住；用户导航入口单独判断 AI 锁定。
- 同媒体服务端保存串行，按媒体保留状态；失败显示错误并允许重试，路由离开前保存，失败留在原页。错误不因自动保存排队或短提示到期而隐藏，只有成功保存才清除。重试入口按失败来源指向保存、删除/反馈原请求；读取失败或版本冲突改为明确重新读取，并先下载本地备份。记住上次媒体与服务端当前帧。
- 精确帧读取超时 20 秒，Tracking / 工作区 JSON 30 秒；慢视频首次提帧与浏览器不支持格式的逐帧播放仍受解码/网络限制。
- 模型任务在后台运行，30 秒是单次 HTTP 请求上限，不是推理总时限。追踪失败独立保留失败阶段与原始帧号；查询超时保持原任务与编辑锁，按钮只重新查询。启动回复丢失时保留输入与幂等键，重试不会在当前后端进程内重复入队；刷新按账号/媒体恢复待查询任务。服务器重启后旧任务不存在时明确告知，不能假报完成。
- Chrome 93 / HTTP 兼容入口为 `src/utils/browserCompat.ts`：超时使用 AbortController 和可清理的计时器，覆盖响应正文读取；UUID v4 使用 HTTP 下可用的 getRandomValues。不要在业务代码直接调用 AbortSignal.timeout / crypto.randomUUID，也不要用时间戳或 Math.random 代替幂等键。重试沿用原键。
- 素材列表只提供“删除素材”，不提供临时关闭入口；暂停处理直接切换素材。垃圾桶按钮先确认范围：服务器视频删除共享原视频、工作区和追踪文件；本地图片仅清除本机工作区素材与标注，保留电脑原文件和服务器已保存记录。服务器删除前停止待发自动保存、等待已发送保存结束，收到后端明确成功才移除本机条目。已送审源视频不可删。成功同步服务端列表时剔除失效的本机视频缓存，网络失败不得清空列表。保留旧关闭记录的 ID 映射读取，用于升级后恢复既有标注身份。

## 删除对象与显式确认

- 对象列表、选中身份、名称和删除入口使用同一面板。`删除本帧`以 `(mediaId, frameIndex, objectId)` 保存排除规则，`删除全视频`以 `(mediaId, objectId)` 保存规则；不要用随机界面 `id` 代替稳定身份。旧 `deletedTrackingIds` 仅用于兼容。
- 全视频删除先读取服务端实际统计（同帧人工优先去重），展示涉及帧数、人工/AI 数与首末原始帧，再确认。读取失败不能当零条，成功写盘前不移除本机对象。删除不物理擦掉追踪原始数据，消费者在读取、seed、后续追踪、送审时统一过滤。
- 单帧撤销恢复原框和删除规则；整视频撤销恢复目标对象自身快照，其他对象修改不回滚。删除暂停对象时清除对应待处理项；撤销需恢复尚未确认的暂停项。普通新编辑使旧的整视频删除重做失效；新追踪分支使旧撤销/重做整体失效。
- 工作区、删除与反馈写入统一串行，使用服务端 `revision` 和 `Idempotency-Key`。反馈前先保存人工修框，成功才清对应暂停项；全部处理后才自动从已确认的暂停帧续追。定位失败保留确认结果并要求返回该帧，不在错误帧开始追踪。
- 网络失败保留原 payload/key，禁用新的互斥决定，允许原请求重放；待重试数据与最近一次全视频撤销快照按账号、媒体存于当前标签页 sessionStorage。刷新先重放再 GET 核对状态。版本冲突不自动覆盖另一份工作区，要求重新读取。
- 右上角用户说明唯一源是 `frontend/src/help/user-guide.md`，专注入口复用同一组件；快捷键小窗也从该源的表格生成。

## 稳定 ID 与人工基准

`objectId` 是媒体内稳定正整数；同帧不重复，不按数组顺序或长度生成、重排。seed 同时传 `object_id` / `objectId`，后端拒绝缺失、重复或跨帧身份；SAM3 输出、工作区合并、后续 seed 都沿用该身份。前端合并键为 `(frameIndex, objectId)`，人工修正优先于同对象 AI 结果，并保留删除标记。

异常面积/宽高/长宽比按每个对象最近的人工基准或显式整帧检查点比较。“整帧全部无异常”通过 `scope=frame` 一次确认暂停帧全部有效框（含未报异常对象），以已保存人工框覆盖同 ID 的 AI 框，排除删除对象。服务端从实际数据生成检查点，全部对象事件与暂停解除、版本、回执一次原子写入；缺失框需补框或明确删除。原人工记录和 AI 来源不改写。整帧检查点替换旧尺寸基准，不再用更早的形态放宽判断；同帧或之后的真实人工框优先，未来检查点不影响较早起点。“本对象无异常”显式发送 `scope=object`，仅保存该对象 `checkpoint=true` 的尺寸参考并移除本项，不清其他待处理项。只有同一次暂停中双方分别正常且双框快照仍匹配，或显式整帧正常，才保存共同重叠认可；单方不授予整对正常。旧反馈参照仍兼容，但新单项检查点替换旧形态。普通浏览、保存与 AI 输出不能生成检查点。

普通尺寸风险连续 3 个相邻原始帧才暂停，计数按对象及同类风险隔离；恢复正常、换风险类别或帧不连续会重置观察。明显坍缩/暴增仍即时暂停。追踪可以分析至决定帧 `decision_frame_index`，但返回首次风险帧 `pause_frame_index`，只发布可供用户检查和确认的有效分支；不能让用于观察的后续帧成为已确认正常记录。界限由 `AnomalyConfig` 定义，诊断保留实际比值、所选完整参照、界限和持续次数；前端只显示证据，不自行判断是否暂停。正常任务仍定位 `lastProcessedFrame`，不猜测处理终点。

真实 SAM3 输出另经 `TrackingEvidenceProbe` 核验原生 BGR 与当前占用 Mask ROI。参考只来自有效人工框或显式正常确认，不从 AI seed 自动建立。v2 将身份来源与最新几何绑定分别保存，通过此前可靠位置/外观和邻居候选联合分配主体；同一核不能可靠归属于两个对象。粘连时冻结此前可信位置，分开后重新辨别，不把粘连质心写成可靠身份。距离变换最大圆只是辅助，不能等同精子头部。自己的主体保留时，掩膜混入邻居或局部覆盖不足为 warning，不直接升为合并/掉尾；临时歧义有限观察，超期仍暂停。可靠主体或经验证的临时遮挡不再回退到普通宽高/面积硬停；整体尺度极端仍保护；已确认Mask面积大幅减少仅在当前严格核验且主体可靠、无明确丢失时降为提示，未知身份、遮挡、失效或旧证据仍保留保守坍缩保护。自己的主体丢失、框跟随邻居、真正共用主体、明确框外结构遗漏作为独立图像风险持续核验。缺参考、低对比、缺图/Mask或坏绑定均保留不确定性，按本帧是否有效核验原图/Mask分别提示或采用旧几何兜底；supported 不是完整尾部或标注正确证明。

当前帧 `observationVerified:true` 只表示有效原图、BBox和非空二值Mask的读取及占用核验成功，不表示身份可靠。消费前仍核对 sourceSignature、对象/帧/框/面积及人类参照绑定；缺标志的历史行、坏绑定和读取失败保持旧兜底。已核验但身份未知时保留非阻断提示，普通宽高/面积/长宽比变化不单独成为硬暂停；框整体尺度以同一固定人工/正常参考的对角线比例兜底（<0.40或>2.00），可靠当前主体可将历史Mask面积骤减降为候选提示；空Mask、未知/临时遮挡、坏绑定和独立图像风险不借此豁免。AI输出不能更新这些参照。历史计数恢复使用同一政策，不能在续追时把旧的弱几何观察重新升级成硬停。

光学主体仍可靠、BBox包住至少80%光学核、中心在框内，而Mask覆盖仅轻度不足（40%～60%）时先warning；BBox仅包住不足60%光学核、中心框外或明显Mask缺失继续risk。可靠头部完整但细尾不可辨的 `body_extent_unknown` 为warning，保留身体范围不确定，不证明尾部完整，也不盖掉明确的大段自身框外遗漏。尾部归属需要近头起点到框外支路有连续原图光学支持；仅Hessian弱梯度连通不构成归属，光学路径在其他核处截断。归属不明的框外细线输出 `tail_structure_attribution_uncertain` 和warning，不声明尾部完整；清晰自身支路持续框外仍是独立tail_loss。

历史确认Mask面积低于25%时，严格有效native证据、可靠matched头部且无明确结构丢失才降为SOFT；保存 `mask_area_decision`，实时与历史prime同规则。`tracking.mask_area_candidate` 在首次候选、决策改变时记录，`tracking.mask_area_candidate_cleared` 记录恢复，历史prime不刷候选日志。尾部摘要保留 `tailAttributionUncertain`、各尺度 `unattributedOutsidePixels/opticallyConnectedTailPixels/outsidePointAttributable`，原Mask与BBox不改变。

暂停发布与持久展示共用后端 `classify_pause_reason`，前端按相同HARD原因解释新旧诊断。对角线HARD归为尺寸扩大/缩小，SOFT宽高不覆盖真正运动或图像HARD；没有原始依据的旧记录保持原说明。分类不决定是否暂停、不增加反馈范围或运动学习权限，历史错误标题不会导致暂停自动解除。

`NativeImageEvidence` 只保留一个当前原生帧，按真实帧号独立解码并核对源签名；参考帧分组读取即释放。SAM3 标准插值/二值化与框坐标不改变，每对象仅复制占用 ROI，不累积完整原图 Mask。读取失败记日志并回退未知证据。辅助证据不会改写人工标注、模型权重或几何确认，也不视为人工审查。

重叠按稳定对象对判断：seed 已有且未恶化的重叠为提示，新出现/恶化的同一对象对持续 3 帧才暂停；不能仅凭较小框覆盖率当成身份合并证明。每个对象保留所有相关 `overlap_pairs`，不能以后一个 partner 覆盖前一个。整帧正常确认保存暂停帧所有实际相交对象对的状态；相近状态可续追，但新 partner、明显恶化、框趋同伴随其他风险仍检查。reset、实际修正和回退的时间范围约束同样作用于重叠参考，不永久豁免整个对象。

两对象都有独立、可靠的光学匹配且实际 Mask IoU 很小时，外接框重叠降为提示并清该对旧观察；仅有不同坐标点不构成豁免。Mask 混入邻居与主体真正共用分开检测；确认的共同状态不提供免检期，新伙伴、主体丢失、明显恶化、分开后重叠仍检查。

两对象当前原图/Mask均通过上述核验时，纯BBox高重叠同样仅warning：框趋同不足以单独证明主体合并，不能与同一薄弱假设相互佐证或加速图像风险计数。真正共用主体、丢失和重大遗漏由独立图像观察负责；单对象/整帧正常确认及双边认可边界不变。原图或Mask核验失败、只有旧框记录时保留原重叠兜底，不能把unknown写成supported。

一方 `reference_missing` 时保留unknown，不因缺参考而无限豁免真实共追单核。生产probe可追加 `singleCoreConflict`：当前ROI完整覆盖双方框、两框内只见一个可分辨强核、与另一方可靠头同位、双方真实Mask IoU≥0.90且各自核覆盖≥0.80。消费端重新核对可信partner当前证据及双向Mask交叠，按同一对象/partner连续12帧观察产生 `image_shared_core_unresolved`；新伙伴、帧不连续或第二可见主体恢复会重置，历史续追恢复同样计数。它既不是BBox推测，也不生成身份引用；已知双方真正共核的原图风险仍走原持续规则。

### 运动提示、人工确认和续追

- 位移使用 `motion_normalized = 位移 / 人工框对角线 × FPS / (30 × 真实帧差)`；原图主体可靠时采用主体位移，未知时采用框中心位移，历史和人工正常样本按 referenceKind 分开，不将旧框中心样本当新主体样本。人工尺度缺失时使用固定 seed 尺度；界限集中在 `AnomalyConfig`，没有固定 40/55/60 px 门槛。
- 普通超范围先产生 warning；连续 3 次超范围才暂停。近期轨迹中的有限往返抖动中断持续漂移计数；远超范围的跳跃仍立即暂停。AI 历史最多 8 帧，只用于短期运动证据，不会扩大正常阈值。
- 暂停后显式选择“无异常”或先修正再确认。服务端从保存的追踪结果提取人工确认对应的运动特征；只有选择校准的 `normal` 决定写入本媒体 `normalMotionSamples`，按 `objectId` 和 `reason=motion` 适用。只确认本次、修正、其他异常类型不能变成正常运动样本。
- 校准以已确认样本及有限余量调整同类运动范围；再次人工确认可补充更大样本。刷新、后台重启与续追重新读取持久样本；重置清除该对象的校准，不删除确认审计历史。相似运动在范围内持续追踪，warning 按对象和原因合并计数，不每帧弹窗。
- 正常尺寸及对象对参照随服务端反馈事件持久化，仅对同媒体、同对象/对象对生效；续追只读取不晚于起始帧且未被后续重置/修正取代的参照，不让未来确认影响回退起点。后端保存成功后返回与事件一致的参照摘要，续追检查实际载入，不可默默退回旧基准。恢复默认判断清除运动校准、尺寸和关联重叠认可的使用，审计保留。尺寸确认与运动勾选独立：取消运动校准不撤销对当前尺寸/形状的认可。
- 新的持续超范围运动、明显跳跃、超出已认可形状的尺寸突变、非正常离场的目标丢失、对象重叠仍分别检查；运动校准不会停用这些检测。这里没有在线训练 SAM3，模型推理质量与异常暂停规则是两层功能。
- `tracker_results.json` 保留逐帧位移、归一化值、阈值、持续次数、样本数、近期速度，以及实际几何参照来源/帧号/框、全部重叠组合和暂停/决定帧等诊断；暂停原始证据随工作区持久化，响应丢失或刷新后仍能解释。`review.tracking` 记录 `tracking.anomaly_pause` 与合并警告。发现频繁暂停先查看确认写入、参照载入、实际触发指标和持续次数，再调整规则。仅合成轨迹/模拟推理回归通过不等于真实 GPU 或真实视频效果验收。

暂停区始终保留异常对象选择按钮，包括最后一个；紧凑左对齐排列。点击同步选中同 ID 画布框并切选择工具，用有限平移显示视野外的框，保留缩放；可见目标不移动。错帧点击先返回并可靠读取暂停帧，期间确认仍严格禁用；迟到加载、换素材/暂停或用户另选取消旧定位。仅在真实暂停帧已读入、无失败待重试/互斥操作时自动定位首项或下一项，不抢走用户主动选择的其他对象。消失对象可复用既有“复制上一帧”补全部缺失 ID；上一帧无框时定位最近有框帧并走原分支重建，无历史身份不伪造新框。返回暂停帧、补缺框、回退重追、保存/确认错误与原请求重试直接显示在操作区，不依赖详情展开；收起详情不清除错误或待处理项。浅深主题/小窗口/专注复用同一暂停逻辑和确认处理，完整依据与学习选项按需在详情侧区查看，正常确认清单保留独立折叠入口，不复制第二套决定或重试状态。

## Tracking 回退的精确边界

点击当前 N 帧 Tracking：先保存工作区和当前人工修改，回退旧未来结果，再将 N 帧当前全部 bbox（含仍有效的 AI 对象身份）写入 seed 并启动新分支。普通启动/续追不能隐式确认所有暂停异常，也不能让普通 AI 框自动覆盖最近人工基准。

异常暂停后，用户可在暂停帧逐对象正常/修框确认，或明确确认整帧无异常，或回到更早的帧修正后显式重建分支。本对象正常、逐对象修正和整帧正常入口分开，服务端待处理清空并解除暂停后才自动续追；失败原键正文与 scope 保留；错误或未知结果保持原请求待重试。早帧入口为“从本帧修正并重新追踪”；确认弹窗说明将替换 N 之后的旧 AI 结果并解除旧分支的待处理暂停状态，取消不产生分支变更。N 必须严格早于当前服务器记录的暂停帧，并有有效起始框；暂停帧及之后仍须处理原异常，不能直接绕过。重建不产生 normal/corrected 校准事件，不清历史反馈和正常样本。

早帧重建先保存全部人工修正，再向独立 restart-branch API 提交版本、暂停帧、轮次和幂等键；成功后才清客户端旧暂停/未来 AI、更新版本并启动 seed/模型。未知结果保留原请求，刷新恢复沿用原键；不能因为回退超时就清空暂停或新建分支。恢复已提交回执后仍须核对当前送审状态，已送审不能写 seed 或续追，状态查询失败则保留原起点重试。服务端结果 JSONL、工作区版本与收据通过持久恢复日志协调，失败和重启按提交证据恢复，不能仅凭进程锁声称多文件原子。后续 seed/模型失败与已经完成的分支重建分别恢复，不再截断新生成的未来结果。

续追异常检测的身份名单严格限定为当前 seed；从旧 JSONL 恢复运动历史时同时过滤非活动 ID 和对应删除规则。旧文件中为撤销保留的框不能恢复成消失检测对象。单帧删除不全面关闭该对象未来的异常检查。

当前实现 `tracker.rewind_tracking_results` **保留 ≤N 的行，仅删 >N 的旧未来追踪行**；持久人工标注和基准文件保留。前端只清掉工作区 N 之后的旧 AI 对象和追踪帧，全部已保存人工框（含 N 之后的框）继续保留，保存和刷新不能把它们丢掉；随后新追踪按原始帧身份更新 N 及之后的新结果。旧文档的“删除 >=N”或“删除未来人工 seed 文件”不能照搬。

回退 HTTP 只处理 JSONL，不重编码整段视频；未改变未来行时不重写文件。模型只解码从 seed 开始的本轮连续窗口（含 seed，上限来自实际请求与剩余源帧数），保留原图尺寸、不降低 FPS。SAM3 会话使用窗口内 0 起索引，写盘、异常历史、反馈参照和 API 一律映射回原始帧号；不得直接保存会话下标。长时解码/推理不持有来源锁，追踪中仅允许保存浏览状态，不允许改人工框、基准或删除规则；结果原子发布在短锁内。完整带框视频改为访问 overlay API 时按需生成并校验缓存，画布叠加和训练导出不依赖预览编码。

全程原始 FPS/帧号，无 FPS 降采样、sample-frame 编号或浏览器插值。`SAM3_TRACK_FRAMES` 包含 seed；模型缓存跨任务复用，每个任务建立推理会话，GPU 队列串行。

续追恢复前先绑定当前源文件签名，再核验历史原图/Mask诊断；读取窗口覆盖最长持续观察（默认至少12帧），不能仍只取8帧而丢掉单核长期歧义计数。运动历史本身仍限制8帧。坏 `head.metrics` / `coverage.metrics` 明确拒绝并记录原因，缺省字段兼容；损坏旧诊断不能让模型任务因属性访问异常退出，也不能被升级为有效原图证明。

准备阶段只保留最多 2 张原始帧，调用原 SAM3 video processor 分批预处理后存入 CPU 上的本轮模型输入张量。仍使用预加载视频会话与原 processor 尺寸/归一化/dtype，不改为流式推理、不降低模型分辨率；独立 CPU 对照检查输入张量一致。输出掩码逐对象使用原设备上的标准插值/二值化提取框与面积，不同时扩展全部对象到原图尺寸；常规追踪只保留几何，不积存用不到的完整掩码。真实 GPU 的峰值显存和推理耗时需要另验。

模型首次 `from_pretrained` 就使用配置的推理 dtype，再迁移到原设备，避免先建立整份 FP32 模型再转换为 BF16/FP16；最终推理 dtype 不变。记录 `tracking.model_ready` 的加载耗时，跨任务继续复用同一模型。

回归入口：`test_anomaly_detector.py`、`test_tracking_adaptive_feedback.py`、`test_tracking_rewind.py`、`test_seed_identity.py`、`test_manual_baseline_restore.py`、`test_frontend_tracking_contract.py` 以及 [TESTING.md](TESTING.md) 的浏览器用例。模拟 AI 响应只验证 UI 状态/定位，不代表模型推理通过。

## 三页观看操作对齐

`workbench/useViewportNavigation.ts` 处理审查/确认完整帧的指针锚定缩放与Space/中键平移，`viewTransform.ts` 统一观看键识别和边界数学；人工标注保留原有画布/暂停锚点机制并使用同一缩放键识别。`useWorkbenchFocus.ts` 为B/C保留窗口状态与页头焦点恢复，A暂停专注继续沿用现有独立检查侧栏。可视变换不能写bbox/工作区或产生提交/确认。审查原图比例、人工标注相对适应比例与C局部裁剪倍率不是同一个数值，UI明确完整帧/局部图的控制范围；勿用C原有3–8倍局部滑条代替完整帧缩放。

### 点选头部生成框

视频的 head 工具请求原始源帧局部检测，结果为像素 xyxy，客户端校验帧号/尺寸/有限值后转换百分比并调用既有 addObject，保留稳定 ID、自动保存及帧级撤销。切帧、切工具、离开标注页、工作区变动或编辑锁变化取消待处理请求；重新载入时恢复为画框工具。生成后保持 head 工具以便连续点选；微调时手动切换选择工具（V）。无可信候选、邻近候选歧义、缺模型均返回错误，不生成默认框。本地图片保留手动画框。

## 可选边缘入画发现

兼容 API 的 `TrackRequest.edgeDiscovery` 默认 false；新前端固定发送 true，不提供开关，未决任务仍重放原正文。使用 `head_click.detect_edges` 对原始边缘重叠512像素分块推理，`edge_entry.EntryGate` 做保守关联。初始可见及内部首次检出只作排除项；首次框贴边带（短边1%，至少3px）、至少4个连续原始帧且跨度≥0.15秒、检测分数均≥0.5且中位数≥0.7、扣除phase correlation估计的相机平移后向内移动≥半个头宽高最小值（至少3px）才接纳。歧义、重复、跟丢、低纹理/相机平移不可靠时拒绝新增。此为工程筛选条件，不是生物身份判定或精度保证。

接纳后使用媒体内未占用稳定ID（扫描工作区、删除墓碑、结果和seed），确认帧将提示加入原SAM3 session，重新消费该帧以编码提示再从下一帧继续，保留已有对象记忆。连续检测观测补回首次可见帧；它们是 `edge_detector` AI 来源，不生成手工基准。`entryOrigin` 保留首次/确认帧及humanConfirmed=false。候选状态随每帧结果 `edgeDiscovery` 保存，续追恢复，暂停回退仅发表在返回帧前已确认的新增对象，未来候选不提前出现在旧帧。失败不发表半份结果；当前标注直接导出采用独立快照，历史 A/B/C/F 保持原规则。
