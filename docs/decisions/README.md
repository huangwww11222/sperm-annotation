# 决策记录

只记录**重大方案取舍**：为什么这样做、放弃了什么。规则本身仍写在对应的当前文档（WORKFLOW、ANNOTATION、API 等），这里只解释原因，供人和 AI 工具判断“能不能改回去”。

- 文件名：`NNNN-简短标题.md`，编号递增，不复用。
- 已被取代的决策不删除，在开头注明“已被 NNNN 取代”。
- 日常改动、调试过程、测试记录不写在这里（分别放提交信息、`work/`）。

```markdown
# NNNN 标题

- 日期：YYYY-MM-DD
- 状态：采用 | 已被 NNNN 取代

## 背景
## 决定
## 放弃的方案及原因
## 影响（哪些文档 / 代码 / 数据随之改变）
```
