# 交接记录模板

复制到 `work/HANDOFF.md`（已被 Git 忽略），每次结束一段工作前**整份覆盖**，不追加历史。下一位开发者（人或任一 AI 工具）开工先读它和 `git log -5`。

```markdown
# HANDOFF

- 更新时间 / 工具：YYYY-MM-DD HH:MM，Claude Code | Codex | 人工
- 分支：feat/xxx（是否有未提交改动：有 / 无）

## 当前任务
一句话说明用户要的是什么；需求原文或方案文件路径（如 work/xxx方案.md）。

## 已完成
- 改了哪些文件、做到哪一步
- 已运行的测试与结果（通过 / 失败 / 未执行）

## 下一步
1. ...

## 等用户确认
- 问题、选项、目前建议（没有就写“无”）

## 不要碰
- 正在修改或需要保留原样的文件、目录、数据
```

稳定的规则不要只写在这里：完成后移入对应 `docs/*.md`，取舍写入 `docs/decisions/`。
